## Step 2: 自然言語でコントラクト生成（~5分）

### トークポイント

「では実際にコントラクトを作ってもらいましょう。送金額と送金先を誰にも見せないプライベート決済のコントラクトです。プロンプトは日本語で書きます。」

（プロンプトを入力しながら）

「これがプロンプトです。」

（プロンプトをゆっくり読み上げる）

「Compact言語で、送金額と送金先を非公開にしたプライベート決済コントラクトを作成してください」

「プログラミングの指示は一切していません。何を作りたいかだけを書きました。」

（MCPが動き始めたら）

「見てください。MCPが自動的に動いています。まずCompact言語のシンタックスリファレンスを取得して、次にサンプルコードを参照して、それを元にコントラクトを生成しています。AIが必要な情報を自分で調べながら書いている。」

（コントラクトが生成されたら、コードをスクロールしながら説明）

「生成されたコントラクトを見てみましょう。構造は大きく3つに分かれています。

まずledger — これがブロックチェーン上に記録される公開データです。見てください、balance_commitments というマップが1つだけ。実際の残高ではなく、残高のハッシュ値だけを保存しています。

次にwitness — これが完全に非公開のデータです。private_amount、private_recipient。送金額と送金先がここにあります。これらはブロックチェーンには一切記録されません。

そしてcircuit — これがZKPのロジック本体です。private_transferを見ると、amountもrecipient_pkも全てwitnessから取得しています。チェーン上には何のトレースも残さずに、送金が正しく行われたことだけを数学的に証明します。

暗号数学の知識ゼロで、ここまで書けた。それがMidnight MCPです。」

### 画面操作

1. Claude Codeのプロンプト入力欄に以下を入力:
   ```
   Compact言語で、送金額と送金先を非公開にしたプライベート決済コントラクトを作成してください
   ```
2. Enterを押す
3. MCPがツールを呼び出す過程をリアルタイムで見せる（スクロールしない）
4. 生成完了後、コードをスクロールしながら3つのセクションを指差す
5. `contracts/private-payment/private_payment.compact` を別ウィンドウで開いておくと補助として使える

### フォールバック

生成が途中で止まった・エラーになった場合: 既に生成済みの `contracts/private-payment/private_payment.compact` を開いて「これがMCPで生成したコントラクトです。リハーサルでは問題なく生成できました」と説明してコード解説に移る。

## Step 3: MCPコンパイル＆自動レビュー（~3分）

### トークポイント

「コントラクトが書けたら、次はコンパイルです。普通ならここで環境構築が必要になる。Compactコンパイラをインストールして、設定して、CLIを動かして。でもMCPがあれば、それも全部自動です。」

（コンパイル指示を入力しながら）

「コンパイルしてくださいと伝えます。」

（MCPがコンパイルを開始したら）

「MCPがMidnightのホスト型コンパイラに接続して、コンパイルを実行しています。ローカルに何もインストールしていない。」

（エラーが出た場合）

「エラーが出ました。でも見てください。MCPが自動でエラーを解析して、修正方法を提案しています。」

（自動修正の様子を見せながら）

「disclose() の追加が必要だった箇所を自動で検出して修正しています。Compact言語特有のルール — ウィットネスデータをチェーンに書き込む前には必ずdisclose()で明示的に公開宣言しないといけない。このルール、最初は誰でも引っかかる。でもMCPが教えてくれる。」

（コンパイル成功したら）

「コンパイル成功です。これでデプロイ可能な状態になりました。

今見てもらったのは、ゼロ知識証明のコントラクトを、暗号の専門知識なしに、自然言語だけで作ってコンパイルまで通した、というデモです。Midnight MCPはこの全ての橋渡しをしています。」

### 画面操作

1. Claude Codeに入力:
   ```
   このコントラクトをMCPでコンパイルしてください
   ```
2. MCPのコンパイルプロセスを表示させる
3. エラーが出た場合はそのままMCPの自動修正を見せる
4. コンパイル成功のメッセージを画面に映す

### フォールバック

コンパイラへの接続がタイムアウトした場合: 「ネットワークの状況によってホスト型コンパイラへの接続が遅くなることがあります。バックアップのスクリーンショットで成功した結果を見てもらいます」と言ってバックアップ画像を表示する。

## Step 4: テストネットデプロイ（任意、ネットワーク安定時のみ）（~3分）

### 事前判断基準

本番デモ直前に `https://preprod.midnightexplorer.com/` が開けるか確認。開けない・遅い場合はこのステップを省略してStep 5（まとめ）に移行する。

### トークポイント

「最後に、テストネット（Preprod）へのデプロイを見てもらいます。」

（デプロイ指示を入力しながら）

「デプロイの指示もMCPに任せます。」

（デプロイ完了後、エクスプローラーを開きながら）

「ブロックエクスプローラーでトランザクションを確認してみましょう。

見てください。トランザクションは記録されています。でも、送金額がどこにも表示されていない。送金先アドレスもない。ブロックチェーンは透明なのに、プライバシーが保たれている。これがZKPの力です。

balance_commitmentsには数値ではなくハッシュ値だけが保存されている。送金が正しく行われたことは証明されているのに、いくら送ったか、誰に送ったかは誰にもわからない。」


3. `https://preprod.midnightexplorer.com/` を開いてトランザクションを検索
4. balance_commitmentsのハッシュ値を画面に映す

SIPOではMidnight Ambassadorとして、このMCP×AI開発のワークショップを日本で展開していきます。今日のデモで試してみたい方、企業での導入を検討されている方は、ぜひ声をかけてください。

質問はありますか？」

### よくある質問への回答準備

**Q: MCPとAPIの違いは？**
「APIは機能を呼び出すだけですが、MCPはAIアシスタントが自律的にツールを選択して使えるようにするプロトコルです。AIがコンテキストを理解して、必要なツールを自分で判断して呼び出せるようになります。」

**Q: 本番環境でも使えますか？**
「MCPとCompactコントラクト自体は本番対応していますが、今日のデモはテストネット（Preprod）環境です。Midnightメインネットのローンチ後は本番でも使えます。」

**Q: どんなユースケースに使えますか？**
「プライベート決済以外にも、医療データの共有（誰が何を共有したか隠す）、サプライチェーン（取引条件を非公開に）、投票システム（誰が何に投票したか隠す）など、プライバシーが必要なほぼ全てのユースケースに応用できます。」

**Q: Compact言語を自分で学ぶ必要はありますか？**
「MCPを使えば最初は自然言語だけで始められます。ただ、本番開発では生成されたコードをレビューできる程度の理解は必要になります。ドキュメントはMidnight公式サイトにあります。」

## 緊急時フォールバック一覧

| 状況 | 対応 |
|------|------|
| MCPサーバーが起動しない | `npx midnight-mcp@latest` を直接実行してエラーを確認。Node.jsバージョン確認（v18以上必要） |
| Claude Codeがフリーズ | Ctrl+C で中断して再入力。「先ほどのコントラクトを使って続けましょう」と説明 |
| コンパイラに繋がらない | バックアップスクリーンショットを表示してデモを継続 |
| ネットワーク全断 | 事前生成済みの `contracts/private-payment/private_payment.compact` を開いてコード解説のみ実施 |
| デプロイ失敗 | Step 4をスキップしてまとめに移行。「デプロイは後ほど個別にお見せします」 |
